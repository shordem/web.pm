# Project Management Web App

A modern project management web application built with React, TypeScript, Vite, and Tailwind CSS. The application is designed to help users manage tasks, organize workflows, track project progress, and interact with a clean, responsive dashboard interface.

## Overview

This project focuses on the frontend experience of a project management platform. It includes reusable UI components, structured routing, form handling, API integration patterns, drag-and-drop task movement, and responsive screens for managing project-related workflows.

The goal of the project is to demonstrate a clean, scalable frontend architecture for productivity and project management tools.

## Features

* Project and task management interface
* Responsive dashboard layout
* Task organization and workflow views
* Drag-and-drop task movement
* API request handling with Axios
* Server-state management with React Query
* Form handling with React Hook Form
* User-friendly notifications with React Hot Toast
* Smooth UI interactions with Framer Motion
* Route-based page navigation with React Router
* Reusable frontend components
* Tailwind CSS styling
* TypeScript-based development

## Getting Started

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/shordem/pm.web.git
cd pm.web
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The app should now be running locally.

## Available Scripts

```bash
npm run dev
```
